NEED A LITTLE CLARITY?

Frequently asked questions.

A few things you may want to know about DCN·LINK.

What is DCN·LINK?+

DCN·LINK is an intelligent file-transfer interface designed to demonstrate data exchange between sender and receiver nodes using different communication technologies.

What types of content can I transfer?+

The interface supports text messages, images, videos and general files. Actual transfer capability depends on the connected backend and network implementation.

What does Auto · AI switch mean?+

It represents the adaptive network-selection option. Your backend decision logic should evaluate channel conditions and select an available interface. The front-end selection alone does not perform AI switching.

Which communication interfaces are represented?+

The interface includes FSO, mmWave, Wi-Fi, cellular networks and LoRa/LoRaWAN as selectable communication options.

Can I store transfer information?+

Yes. The interface includes database options intended to connect with PostgreSQL for storing and retrieving transfer records. Database operations require your backend connection.

Does the animation show a real network connection?+

The animated network graphic is a visual representation. Real connection status, transmission progress and switching decisions must be supplied by the application backend.
